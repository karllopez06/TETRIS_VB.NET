# 🎮 Tetris Trivia — VB.NET

A classic Tetris clone with a twist, developed in VB.NET as a first-year programming project.

## 📖 About

This is a Tetris game where the fun doesn't stop at clearing lines. Every time you hit a 1,000-point milestone, the game pauses and throws a general knowledge question at you. Answer correctly and you'll earn bonus points — but get it wrong and your score takes a hit. It's a mix of fast-paced puzzle gameplay and quick trivia thinking.

## 🎯 Features

- Classic Tetris gameplay (falling pieces, line clearing, increasing speed)
- Trivia system that triggers every 1,000 points
- Bonus points awarded for correct answers
- Score deduction for incorrect answers
- Built entirely in VB.NET using Windows Forms

## 🛠️ Built With

- VB.NET
- Windows Forms (.NET Framework)
- Visual Studio

## 🚀 How to Run

1. Clone or download this repository
2. Open the `.sln` file in Visual Studio
3. Build and run the project (F5)

## 📚 Background

This project was made during my first year of programming as part of a school/university project. It was a great exercise in combining game logic, UI design, and event-driven programming in VB.NET.
